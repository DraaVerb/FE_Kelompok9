# Kopi Nusantara - Bootstrap 5

## File
- `index.html` : struktur halaman dan komponen Bootstrap
- `style.css` : kustomisasi identitas visual Kopi Nusantara
- `script.js` : interaksi Modal Bootstrap

## Bootstrap yang digunakan
- `container`, `row`, `col-12`, `col-md-6`, `col-lg-4`
- `navbar`, `navbar-expand-lg`, `navbar-toggler`, `collapse`
- `card`, `card-body`, `card-title`, `card-text`
- `modal`, `modal-dialog`, `modal-content`
- `accordion`, `accordion-item`, `accordion-button`, `accordion-collapse`
- Utility: `py-5`, `p-4`, `mb-3`, `d-flex`, `flex-column`, `flex-grow-1`, `text-center`, `rounded-4`, `shadow-sm`, `ms-auto`, `g-4`, dan lainnya.
